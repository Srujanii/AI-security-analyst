# SentinelAI – AI Security Analyst

## 📌 Project Overview
SentinelAI is an AI-assisted cybersecurity project designed to analyze security alerts and explain potential threats in simple, human-readable language. It demonstrates how machine learning concepts can help security analysts understand and classify suspicious activities.

## 🎯 Problem Statement
Security systems generate many alerts every day. Manually analyzing each alert can be time-consuming. SentinelAI aims to make alert analysis easier by organizing security alerts and providing understandable explanations.

## ✨ Features
- Interactive cybersecurity dashboard
- Security alert analyzer
- Sample alerts for brute-force attacks, port scanning, malware, and normal activity
- Threat classification and severity assessment demonstration
- Machine learning model comparison cards
- AI-generated-style security insights
- Security analysis workflow visualization
- Responsive user interface

## 🛠️ Technologies Used
- HTML – webpage structure
- CSS – styling and layout
- JavaScript – user interactions
- Machine Learning concepts – security alert classification

**Note:** The HTML interface references machine learning models, but the frontend alone does not verify that a trained model or backend is connected.

## 🤖 Machine Learning Algorithms
The project presents these algorithms for comparison:
- Random Forest
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)

## 📂 Project Structure

## 🚀 How to Run
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a browser.
4. Alternatively, open the folder in VS Code and use the Live Server extension.
